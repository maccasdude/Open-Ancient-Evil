FFmpeg 6.1.1 (https://ffmpeg.org), GNU Lesser General Public License 2.1 or
later (https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html):
  libavformat, libavcodec, libswscale, libswresample and libavutil, built
  with only the decoders the game needs (see tools/build-windows.sh in the
  Open AncientEvil source for the exact configuration). The FFmpeg source is
  available from https://ffmpeg.org/releases/ffmpeg-6.1.1.tar.xz. The
  libraries are linked statically; the complete source of Open AncientEvil
  and the build script are published, so the program can be rebuilt and
  relinked against a modified FFmpeg.

The mingw-w64 runtime and libstdc++ (GCC runtime library exception) are
linked statically as well.
